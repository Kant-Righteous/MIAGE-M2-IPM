# Site commercial

Mini projet React : trois pages (Accueil, Produits, Commande) avec React Router, sans serveur.

## Lancer le projet

```bash
npm install
npm run dev
```

Puis ouvrir l'adresse affichée dans le terminal (par défaut http://localhost:5173).

Les données de départ sont dans `src/model/products.json` ; elles sont gardées en mémoire et reviennent à l'état initial quand on recharge la page.
