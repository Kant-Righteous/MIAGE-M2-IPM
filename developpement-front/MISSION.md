# Mission: 从 JavaScript 入门到完成 React 课程

## Why
完成当前课程中的 React 学习与练习，从 JavaScript 基础开始建立能够独立阅读和编写 React 代码的能力。

## Success looks like
- 能使用 JavaScript 的变量、函数、数组、对象和模块语法完成小练习。
- 能解释 JSX、组件、Props、State 和 Hook 的作用。
- 能独立完成课程中的用户卡片、计数器、表单和产品管理练习。
- 能使用 Vite 启动 React 项目，并定位常见的运行错误。

## Constraints
- 具备 Java 面向对象编程基础，但 JavaScript 是初学阶段。
- 按课程文件的顺序学习，每次只掌握一个小主题。
- 通过代码预测、小练习和纠错确认理解后再进入下一主题。

## Out of scope
- 暂不深入 TypeScript、Next.js、React Native 和后端开发。
