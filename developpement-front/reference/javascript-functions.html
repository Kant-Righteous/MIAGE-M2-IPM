JavaScript 函数速查表

函数是 React 函数组件和事件回调的基础。

普通函数

function greet(name) {
  return `Hello, ${name}`;
}

greet("Ada");

箭头函数

const add = (a, b) => a + b;
const double = number => number * 2;

单个参数可以省略括号；多个参数需要括号。使用大括号时，通常要明确写 return。

函数组成

部分作用
函数名标识并调用函数
参数接收外部数据
函数体描述执行逻辑
return返回计算结果
