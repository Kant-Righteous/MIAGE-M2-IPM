数组与对象速查表

React 中最常见的数据结构。

数组

const hobbies = ["Reading", "Traveling"];
hobbies[0];
hobbies.length;
hobbies.push("Gaming");

数组索引从 0 开始。

对象

const user = {
  name: "Ada",
  age: 20,
};

user.name;
user.age = 21;
user.email = "ada@example.com";

嵌套

const user = {
  hobbies: ["Reading", "Gaming"],
};

user.hobbies[0];
