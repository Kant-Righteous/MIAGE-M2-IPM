数组遍历与转换速查表

处理 React 列表数据时最常用的三个工具。

for...of

for (const item of items) {
  console.log(item);
}

逐个读取元素，不自动生成新数组。

map()

const result = items.map((item) => {
  return transform(item);
});

转换每一项，返回新数组。

filter()

const result = items.filter((item) => {
  return condition(item);
});

保留回调函数返回 true 的元素，返回新数组。

选择方法

需求选择
逐个执行操作for...of
每项变成新值map()
只保留符合条件的项filter()
