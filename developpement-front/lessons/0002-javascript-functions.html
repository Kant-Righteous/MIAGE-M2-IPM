函数：把行为封装起来

React 的组件本质上是函数。先学会函数，再理解组件为什么这样写。

本课目标

  • 定义并调用函数。
  • 理解参数和返回值。
  • 读懂箭头函数，初步理解回调函数。

1. 定义函数与调用函数

函数是一段可以重复执行的代码。定义函数只是描述它要做什么；调用函数才会真正执行它。

function greet(name) {
  return "Hello, " + name;
}

const message = greet("Ada");
console.log(message); // "Hello, Ada"
代码部分含义
function greet定义一个名为 greet 的函数
name参数，函数接收的数据
return把结果交还给调用者
greet("Ada")调用函数并传入参数

2. 参数和返回值

参数让同一个函数处理不同的数据；返回值让函数的结果可以被保存、显示或继续计算。

function add(a, b) {
  return a + b;
}

const total = add(3, 4);
console.log(total); // 7

这里的 a 和 b 是参数，3 和 4 是调用时传入的实参。

Java 对照：Java 方法中的参数和 return 与这里的概念相似，但 JavaScript 函数不要求提前声明返回类型。

3. 箭头函数

箭头函数是更紧凑的函数写法。React 课程中会经常看到它，尤其是事件处理和数组处理。

function double(number) {
  return number * 2;
}

const doubleAgain = (number) => {
  return number * 2;
};

const doubleShort = (number) => number * 2;

当函数体只有一个表达式时，可以省略大括号和 return。如果写了大括号，就要明确写出 return。

const add = (a, b) => a + b;
console.log(add(2, 5)); // 7

4. 函数也可以作为数据

JavaScript 可以把函数放进变量、作为参数传给另一个函数。这种被传入的函数叫回调函数。

function execute(operation) {
  return operation(3);
}

const result = execute((number) => number * 2);
console.log(result); // 6

React 的 onClick、数组的 map 和很多 Hook 都会用到这种“把函数交给别人稍后调用”的模式。

5. JavaScript 函数与 React 的连接

function Welcome() {
  return "欢迎学习 React";
}

现在它只是一个返回字符串的普通 JavaScript 函数。下一阶段把返回值换成 JSX，它就会成为一个最简单的 React 函数组件。
