变量与数据类型

先学会 JavaScript 的基本词汇，再进入 JSX 和 React。

本课目标

  • 区分 const 和 let。
  • 识别字符串、数字、布尔值、undefined 和对象。
  • 看懂 JavaScript 变量声明，为后续 JSX 做准备。

1. 变量是什么

变量是一个名字，用来指向程序正在使用的值。Java 中常见的声明是“类型 + 名称”；JavaScript 通常不在变量前写类型。

String name = "Ada"; // Java

const name = "Ada"; // JavaScript

JavaScript 是动态类型语言：变量声明时通常不写类型，运行时才确定当前值的类型。

2. const 和 let

const course = "React";
let lesson = 1;

lesson = 2;       // 可以重新赋值
// course = "Vue"; // TypeError：不能重新赋值
关键字 能否重新赋值 初学阶段的建议
const 不能 默认优先使用
let 可以 值确实需要变化时使用
var 可以 暂不使用，后续解释历史原因
重要：const 限制的是变量重新指向另一个值，不等于对象内部完全不可修改。React 中我们会进一步学习为什么通常要创建新对象。

3. 常见数据类型

const studentName = "Ada"; // String：文本
const age = 20;             // Number：数字
const isStudent = true;     // Boolean：真或假
let futureJob;              // undefined：还没有赋值
const student = {           // Object：一组相关数据
  name: "Ada",
  age: 20,
};

字符串必须使用引号；数字不使用引号。"20" 是文本，20 才是数字。

const textAge = "20";
const numericAge = 20;

console.log(typeof textAge);    // "string"
console.log(typeof numericAge); // "number"

4. Java 对照
