数组与对象

React 页面展示的数据，通常就来自数组和对象。

本课目标

  • 创建数组，并通过索引读取数据。
  • 创建对象，并通过属性读取和修改数据。
  • 理解数组、对象和嵌套数据的关系。

1. 数组：一组有顺序的数据

数组适合保存多个相关值。数组的第一个元素索引是 0，不是 1。

const hobbies = ["Reading", "Traveling", "Gaming"];

console.log(hobbies[0]); // "Reading"
console.log(hobbies[1]); // "Traveling"
console.log(hobbies.length); // 3
写法含义
hobbies[0]读取第一个元素
hobbies[2]读取第三个元素
hobbies.length读取元素数量

2. 修改数组

数组是对象的一种。即使数组变量使用 const，也可以修改数组内部的元素。

const skills = ["Java", "HTML"];

skills[1] = "JavaScript";
skills.push("React");

console.log(skills); // ["Java", "JavaScript", "React"]
区分两件事：const 不允许变量重新指向另一个数组，但允许修改当前数组的内容。React 中更新状态时通常会使用“创建新数组”的方式，后面会专门学习。

3. 对象：描述一个实体

对象适合保存一个实体的多个属性。它和 Java 的对象都能表达“一个实体拥有多个数据”，但 JavaScript 可以直接使用对象字面量，不必先定义类。

const user = {
  name: "John Doe",
  age: 40,
  email: "john.doe@gmail.com",
};

console.log(user.name);  // "John Doe"
console.log(user.age);   // 40
console.log(user.email); // "john.doe@gmail.com"

最常用的是点号写法：user.name。也可以使用方括号写法：user["name"]。

4. 修改对象属性

const user = {
  name: "John Doe",
  age: 40,
};

user.age = 41;
user.email = "john@example.com";

console.log(user);

可以修改已有属性，也可以添加新属性。这个灵活性很方便，但在 React 状态管理中不能随意直接修改对象，后面会学习安全的更新方式。

5. 嵌套数据

真实应用的数据通常会嵌套：一个对象可以包含数组，一个数组也可以包含多个对象。

const user = {
  name: "John Doe",
  age: 40,
  hobbies: ["Reading", "Traveling", "Gaming"],
};

console.log(user.hobbies[0]); // "Reading"

const products = [
  { name: "Keyboard", price: 49 },
  { name: "Mouse", price: 25 },
];

console.log(products[0].name); // "Keyboard"
console.log(products[1].price); // 25

这正是课程第一个用户卡片练习的数据形状：用户是对象，爱好是对象内部的数组。

7. 小测验

先预测，再选择。注意数组从索引 0 开始。

问题 1：输出什么？

const fruits = ["Apple", "Banana"];
fruits[0];

问题 2：输出什么？

const user = { name: "Ada", age: 20 };
user.age;

const numbers = [10, 20, 30];
numbers.length;
