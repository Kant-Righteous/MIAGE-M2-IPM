Lesson 04 · JavaScript foundation

数组遍历与转换

学会处理一组数据，为 React 列表渲染做好准备。

本课目标

  • 使用 for...of 依次读取数组元素。
  • 使用 map() 把数组转换成新数组。
  • 使用 filter() 筛选出符合条件的元素。
  • 区分“遍历”“转换”和“筛选”。

1. for...of：依次读取元素

for...of 每次把数组中的一个值交给循环变量。它直接得到元素，不需要手动使用索引。

const hobbies = ["Reading", "Traveling", "Gaming"];

for (const hobby of hobbies) {
  console.log(hobby);
}

// Reading
// Traveling
// Gaming
Java 对照：这很像 Java 的增强型 for 循环：for (String hobby : hobbies)。

如果你需要索引，可以使用传统的 for 循环；本课先使用更容易阅读的 for...of。

2. map()：每项转换成一个新值

map() 会调用回调函数处理每个元素，并返回一个新的数组。通常新数组和原数组长度相同。

const numbers = [1, 2, 3];

const doubled = numbers.map((number) => {
  return number * 2;
});

console.log(doubled); // [2, 4, 6]
console.log(numbers); // [1, 2, 3]

这里的回调函数接收一个数字，并返回它的两倍。map() 把三个返回值组成新数组。

箭头函数可以让写法更短：

const doubled = numbers.map((number) => number * 2);

3. filter()：只保留符合条件的元素

filter() 也会逐个调用回调函数，但回调函数必须返回布尔值。返回 true 的元素会被放进新数组。

const ages = [12, 18, 20, 15];

const adults = ages.filter((age) => age >= 18);

console.log(adults); // [18, 20]
console.log(ages);   // [12, 18, 20, 15]
方法用途返回结果
for...of逐个执行操作没有自动新数组
map()转换每一项转换后的新数组
filter()筛选部分元素符合条件的新数组

4. 对象数组

React 中经常处理“对象组成的数组”。回调函数的参数就是当前正在处理的对象。

const products = [
  { name: "Keyboard", price: 49 },
  { name: "Monitor", price: 220 },
  { name: "Mouse", price: 25 },
];

const productNames = products.map((product) => product.name);
console.log(productNames); // ["Keyboard", "Monitor", "Mouse"]

const affordable = products.filter((product) => product.price < 100);
console.log(affordable); // Keyboard 和 Mouse

5. React 的连接

下一阶段学习 JSX 后，map() 可以把数据数组转换成一组界面元素：

const hobbies = ["Reading", "Traveling"];

const items = hobbies.map((hobby) => (
  <li key={hobby}>{hobby}</li>
));

现在先记住：数据数组经过 map() 后，可以变成要展示的元素数组。
